# Aerografia79

**Arte con alma, técnica con corazón.**  
Sitio web personal para mostrar trabajos de aerografía artística realizados por Eladio Rey-Santacruz.

---

## 🎨 Descripción

Este proyecto es una galería web en desarrollo donde se exhiben distintos tipos de trabajos artísticos como:

- Pintado de retratos
- Personalización de cascos
- Lacado de faros
- Pintado de llantas

También se incluye acceso a redes sociales como Instagram.

---

## 🚀 Tecnologías utilizadas

- HTML5
- CSS3 (con Grid y Flexbox)
- Font Awesome (para iconos sociales)
- Github pages (para despliegue gratuito)
